# 测试点：往来页面新增「最近发生」字段与排序

> 需求来源：庄周产品稿 mockupId=123541（财赢企业端 h5 往来对账）；快照见 `requests/往来页面新增最近发生字段与排序-20260929-1635/requirement.md`
> 材料不含接口文档 → 只出功能用例。

## 模块 1：排序功能（方法：等价类划分 + 错误推测）

排序选项为枚举集合（账龄降序 / 往来金额降序 / 最近发生降序），按等价类每类取代表值验证排序结果正确性。

- TP1.1 排序下拉默认选中「账龄降序」（原「最长账龄降序」改名，排序位置与原来一致）——回归改名后默认态不丢失（等价类-有效）
- TP1.2 选择「最近发生降序」→ 列表按最近发生时间降序排列（新增排序项正例，等价类-有效）
- TP1.3 选择「往来金额降序」→ 列表按往来金额降序排列（原有功能回归，等价类-有效）
- TP1.4 选择「账龄降序」→ 列表按账龄降序排列（原有功能回归，等价类-有效）
- TP1.5 排序切换后再次进入页面/刷新，排序状态保持或恢复默认的行为符合设计（状态保持，错误推测）
- TP1.6 多条往来单位「最近发生」年月相同或为空时的排序表现稳定（数据并列/缺值，错误推测-P4）

## 模块 2：「最近发生」提示气泡（方法：场景法 + 错误推测）

- TP2.1 点击「最近发生」旁提示 icon → 弹出气泡，展示业务背景文案「这些是货款之外还没收回来的钱，比如保证金」（基本流）
- TP2.2 点击气泡外其他区域/再次点击 icon → 气泡关闭（备选流）
- TP2.3 气泡展开状态下切换排序/滚动列表 → 气泡不遮挡排序选项、不残留错位（备选流，错误推测）
- TP2.4 提示 icon 在 6 个往来页面均存在且样式一致（错误推测-一致性）

## 模块 3：列表项字段展示（方法：等价类划分 + 边界值分析）

字段格式：`账龄X丨最近发生YYYY.MM`，账龄区间为枚举（1年以内/近1年/近2年/3年以上等，以账龄分布区间为准），最近发生为 YYYY.MM 格式。

- TP3.1 列表项按「账龄X丨最近发生YYYY.MM」顺序展示，示例：账龄近2年丨最近发生2026.02（字段顺序正例，P1 关键展示）
- TP3.2 账龄各区间展示正确：覆盖 1年以内 / 近1年 / 近2年 / 3年以上 各区间代表值（等价类-有效）
- TP3.3 账龄区间边界值：账龄恰好 1年 / 2年 / 3年 跨界数据落入正确区间（边界值上点/离点）
- TP3.4 「最近发生」年月格式统一为 YYYY.MM，年份跨 2024/2025/2026 等均正确展示（等价类+边界值）
- TP3.5 往来单位无「最近发生」数据时的兜底展示（缺值场景，错误推测-P4）

## 模块 4：六页面一致性覆盖（方法：判定表）

条件维度 = 6 个往来页面（待收 / 其他待收 / 待付 / 其他待付 / 待开票 / 待收票）× 变更点（排序项 / 提示icon / 字段展示），逐格确认覆盖。

- TP4.1 待收页面：新增排序项、提示icon、「账龄丨最近发生」字段展示均生效
- TP4.2 其他待收页面：同上三点均生效
- TP4.3 待付页面：同上三点均生效
- TP4.4 其他待付页面：同上三点均生效
- TP4.5 待开票页面：同上三点均生效
- TP4.6 待收票页面：同上三点均生效
- TP4.7 六页面原有功能回归：核对确认/暂存/同步上期/导出/搜索不受本次改动影响（回归，错误推测）

## 模块 5：筛选区样式（方法：错误推测）

- TP5.1 各筛选项之间的间距调整为 40，视觉与设计稿一致（P3 样式）
- TP5.2 筛选项文案较长/企业名称过长时，间距调整后不换行错位、不遮挡（极端样式，P4）
