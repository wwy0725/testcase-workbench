# 财赢-票家家复制开票对接小程序和APP-测试点-1

> 需求：STORY #254464 【财赢】支持票家家新上的功能对接到小程序和APP（复制开票）
> 材料不涉及接口 → 仅功能用例。设计方法：场景法（入口与跳转主流程）+ 判定表（权限×端×AI命中组合）+ 等价类（问法/角色）+ 错误推测兜底。

## 模块一：更多设置-复制开票入口（小程序 + APP）

| 编号 | 测试点 | 设计方法 |
|---|---|---|
| 1.1 | 有票家家授权（FPKJ_QYZK）：小程序【更多设置】展示"复制开票"入口，名称/样式与 ued 一致 | 场景法-基本流 |
| 1.2 | 有票家家授权：APP【更多设置】展示"复制开票"入口，名称/样式与 ued 一致 | 场景法-基本流 |
| 1.3 | 小程序点击"复制开票"入口 → 正确进入票家家复制开票功能页 | 场景法-基本流 |
| 1.4 | APP 点击"复制开票"入口 → 正确进入票家家复制开票功能页 | 场景法-基本流 |
| 1.5 | 判定表：票家家授权过期 → 入口展示与点击行为与票家家既有细分功能（如快捷开票）一致（入口展示规则 + 到期提示） | 判定表 |
| 1.6 | 权限后台取消该角色票家家勾选 → 该角色用户双端【更多设置】不再展示"复制开票"（App 端双重校验中的角色维度） | 判定表 |
| 1.7 | 错误推测：无权限企业刷新/重新登录后入口消失，无缓存残留 | 错误推测 |
| 1.8 | 错误推测：菜单/授权接口超时或返回异常 → 入口按未命中处理（不展示），页面不报错不崩溃 | 错误推测 |

## 模块二：首页 AI 问答命中复制开票与跳转

| 编号 | 测试点 | 设计方法 |
|---|---|---|
| 2.1 | 有票家家权限：首页 AI 问答提问"复制开票" → 命中发票设置（invoicing_settings）卡片，描述文案正确 | 场景法-基本流 + 等价类有效类 |
| 2.2 | 点击命中的发票设置卡片 → 跳转全部应用并打开【更多设置】抽屉 | 场景法-基本流 |
| 2.3 | 等价类：同义/扩展问法（"怎么复制开票""复制上一张发票再开一张"等）→ 按意图识别配置命中发票设置 | 等价类划分 |
| 2.4 | 判定表：无票家家权限 → AI 对话无命中，返回兜底"不好意思呀，暂时没有找到对应的功能～"，不展示卡片 | 判定表-非法组合 |
| 2.5 | 判定表：票家家授权过期 → 按票家家过期规则返回（卡片正常返回不可操作 + 进入提示到期，消息不显示） | 判定表-边界组合 |
| 2.6 | 共享权限回退：AI 开票（SZGC_AIKP）到期或不存在、票家家（FPKJ_QYZK）有效 → 意图识别回退按票家家逻辑判断，返回发票设置卡片并可正常跳转 | 因果图/判定表 |
| 2.7 | 错误推测：提问含特殊字符/超长文本 → 不崩溃，走正常识别或兜底文案 | 错误推测 |

## 模块三：权限控制（双端 + AI 联动）

| 编号 | 测试点 | 设计方法 |
|---|---|---|
| 3.1 | 权限矩阵判定表：无票家家授权 → 双端【更多设置】无"复制开票"入口 + AI 对话无命中（需求明确的两处联动） | 判定表 |
| 3.2 | 权限后台按角色勾选/取消（老板/员工/财务可配置）→ 双端入口与 AI 命中随角色联动 | 等价类（角色维度）+ 判定表 |
| 3.3 | 机构身份用户（会计/顾问/开票员）→ 按票家家既有规则判断"复制开票"可见性（票家家为企业身份功能） | 等价类（身份维度） |
| 3.4 | 错误推测：权限配置非法 auth_type / 授权码为空 → 按不可见处理不报错 | 错误推测 |
| 3.5 | 错误推测：授权刚到期边界（当天到期）→ 入口与 AI 命中行为符合过期规则 | 边界值 |

## 优先级预估

- P1：1.1、1.2、1.3、1.4、2.1、2.2、3.1（核心交付 + 权限阻塞场景）
- P2：1.5、1.6、2.4、2.5、2.6、3.2（重要规则正例/异常规则）
- P3：1.7、1.8、2.3、3.3、3.4（辅助/异常容错）
- P4：2.7、3.5（极端场景）
