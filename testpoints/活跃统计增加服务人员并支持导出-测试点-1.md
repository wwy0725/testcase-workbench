# 活跃统计增加服务人员并支持导出 - 测试点 1

## 需求概述

- 需求来源：禅道 STORY-251962（https://zentao.dc.servyou-it.com/pro/story-view-251962.html）
- 设计稿：代账宝-活跃统计.pdf（已解码）

本期在代账宝「活跃统计 > 客户活跃明细」页面做两项增强：
1. 客户活跃明细表格新增"服务人员"维度（服务顾问、税务会计、账务会计三列），列位置在"客户名称"后、"登录天数"前
2. 客户活跃明细支持导出 Excel

## 业务背景（知识库补强）

来自业务知识库 `caiying/_raw/财赢企业端/财赢企业端开通流程/活跃统计.md` 及历史用例沉淀：

| 业务点 | 知识库依据 | 对用例的补强 |
|---|---|---|
| 统计范围 | 活跃漏斗=当前机构下所有代账企业；其他模块（含客户活跃明细）=已开通且符合服务开通角色权限的企业 | 服务人员列/筛选/导出用例的前置条件须限定"已开通企业"范围 |
| 数据来源 | 数仓表 `ads_cy_company_active_detail`，按 `event_month` 月份取数 | 导出文件名月份段与取数月份口径一致 |
| 登录/活跃数据口径 | 已剔除机构内部账号的操作（历史用例 262/263 验证悬浮提示） | 服务人员列不影响既有"登录天数"等列的取数口径 |
| 服务人员取值 | 取自客户模块→客户资料→服务人员对应字段，按客户当前绑定取值，客户换人自动更新（实时取值非快照） | 新增"客户换人自动更新"场景法用例 + 接口实时返回用例 |
| 未维护展示 | 未维护该字段列显示"—"（破折号） | 无效等价类用例预期为"—"而非空白 |
| 客户去重 | 客户活跃明细按企业去重展示，支持各字段排序 | 服务人员列同样支持排序（⇅ 标记） |

## 测试设计方法选择

| 被测功能 | 设计方法 | 选用理由 |
|---|---|---|
| 服务人员列展示 | 等价类划分 + 判定表 + 场景法 + 错误推测 | 有值/无值等价类；三字段有值无值组合判定表；客户换人更新场景法；超长/特殊字符错误推测 |
| 服务人员筛选 | 等价类划分 + 判定表 + 正交实验 + 错误推测 | 单条件等价类（三下拉各选一个）；多条件组合判定表；叠加搜索+时间范围场景法；空态错误推测 |
| 导出功能 | 场景法 + 边界值 + 错误推测 | 有数据/无数据/筛选后导出场景；大数据量边界；重复点击防重错误推测 |
