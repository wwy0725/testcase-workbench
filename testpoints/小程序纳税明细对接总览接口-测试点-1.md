# 测试点 — 小程序纳税明细对接总览接口

## 需求概述
8月纳税明细页面由离线数仓改为对接总览接口实时取值，支持AI顾问发送完税通知时用户点击卡片实时查看申报数据。涉及：总览接口对接取值（个税/企税/印花税合计，财报不展示）、传参规则（本期/本年累计）、数据切换时点（2026年1月起）、交互调整（智能提醒/财赢消息入口统一为首页【查税金】卡片）、AI顾问完税通知跳转。

---

## 模块一：总览接口取值（核心）

### 测试点 1.1 — 税种取值范围
- **目标**：验证总览接口返回的税种中，个税、企税、印花税需加工合计值，财报不展示
- **关键规则**：
  - 个税 = 个税（代扣代缴）+ 个税（生产经营）
  - 企税 = 企税（月季）+ 企税（年）
  - 印花税 = 印花税 + 印花税（次）+ 印花税（年）
  - 财报（月季）、财报（年）不展示
- **验证维度**：
  - 返回字段是否仅包含上述3个税种合计值
  - 个税合计值 = 代扣代缴 + 生产经营（数值正确性）
  - 企税合计值 = 月季 + 年
  - 印花税合计值 = 印花税 + 次 + 年
  - 财报字段不在返回结果中

### 测试点 1.2 — 本期值传参
- **目标**：验证取本期值时传参为年月（如2026-06）
- **关键规则**：总览接口按区间传参，取本期值传年月
- **验证维度**：
  - 请求参数格式：startDate=202606, endDate=202606（或等价年月格式）
  - 返回数据为单月数据
  - 边界：1月、12月

### 测试点 1.3 — 本年累计值传参（历史年）
- **目标**：验证历史年取本年累计时传1-12月
- **关键规则**：历史年取本年累计值传对应年1-12月
- **示例**：2027年查2026年本年累计 → 传2026年1-12月
- **验证维度**：
  - 请求参数：startDate=202601, endDate=202612
  - 返回数据为全年累计值
  - 边界：2025年及之前（应走数仓，见模块三）

### 测试点 1.4 — 本年累计值传参（本年）
- **目标**：验证本年取本年累计时传1月至自然月-1
- **关键规则**：本年取本年累计值传1至自然月-1
- **示例**：2026年6月查本年累计 → 传2026年1-5月
- **验证维度**：
  - 请求参数：startDate=202601, endDate=202605（当前6月）
  - 返回数据为1-5月累计值
  - 边界：1月时无数据（自然月-1=0，需确认规则）

## 模块二：数据切换时点

### 测试点 2.1 — 2025年及之前走数仓
- **目标**：验证2025年及之前的数据仍取数仓，展示不变
- **关键规则**：2025年及之前的数据仍然取数仓的，展示不变
- **验证维度**：
  - 查询2025年任意月份 → 走数仓接口
  - 查询2024年及更早 → 走数仓接口
  - 返回数据格式/内容与上线前一致

### 测试点 2.2 — 2026年1月起走总览接口
- **目标**：验证2026年1月及之后数据走总览接口
- **关键规则**：2026年1月开始改成总览接口取值
- **验证维度**：
  - 查询2026年1月 → 走总览接口
  - 查询2026年6月 → 走总览接口
  - 查询2027年（如有） → 走总览接口

### 测试点 2.3 — 跨年度查询
- **目标**：验证查询区间跨越2025-2026时的处理
- **验证维度**：
  - 查询2025-12至2026-01区间 → 两端分别取不同数据源
  - 展示是否正确拼接

## 模块三：首页【查税金】卡片交互调整

### 测试点 3.1 — 智能提醒入口
- **目标**：验证【智能提醒】>【申报完成提醒】点击后调整为首页【查税金】卡片
- **关键规则**：点击交互修改，调整为在首页出【查税金】卡片
- **验证维度**：
  - 点击申报完成提醒 → 跳转/展示首页【查税金】卡片
  - 卡片展示正确样式
  - 不再跳往原有页面

### 测试点 3.2 — 财赢消息入口
- **目标**：验证【财赢消息】>【服务通知】>【申报完成通知】点击后调整为首页【查税金】卡片
- **关键规则**：调整为在首页出【查税金】卡片（同3.1）
- **验证维度**：
  - 点击申报完成通知 → 跳转/展示首页【查税金】卡片
  - 与3.1交互一致

## 模块四：AI顾问完税通知跳转

### 测试点 4.1 — 完税通知卡片链接
- **目标**：验证AI顾问发送《完税通知》时携带小程序链接及卡片
- **关键规则**：财赢提供接口查询纳税明细的小程序链接及卡片
- **验证维度**：
  - 完税通知消息包含可点击卡片
  - 卡片链接为小程序路径
  - 渠道参数 source=aigw-sbwc

### 测试点 4.2 — 跳转小程序首页【查税金】
- **目标**：验证点击完税通知卡片后跳转小程序首页【查税金】页面
- **关键规则**：跳转页面为首页 > 查税金卡片
- **验证维度**：
  - 点击卡片 → 打开小程序
  - 落地页为首页
  - 直接定位到【查税金】卡片/入口
  - 渠道参数正确传递（source=aigw-sbwc）

## 模块五：异常场景

### 测试点 5.1 — 总览接口超时/异常
- **目标**：验证总览接口不可用时的降级处理
- **验证维度**：
  - 总览接口超时 → 展示降级文案或兜底数据
  - 总览接口返回空 → 展示空态
  - 接口返回错误码 → 友好提示

### 测试点 5.2 — 无申报数据
- **目标**：验证用户无任何申报数据时的展示
- **验证维度**：
  - 新企业/无申报记录 → 展示空态或引导文案

### 测试点 5.3 — 网络异常
- **目标**：验证网络不稳定时的用户体验
- **验证维度**：
  - 断网打开页面 → 展示网络异常提示
  - 弱网 → 加载超时提示
