# 测试点 — 财赢仅白名单机构显示方形logo入口

> 关联需求: REQ_252182（禅道 story-view-252182）
> 生成时间: 2026-09-02

## 需求概述

方形logo仅应用于 AI 顾问小程序卡片消息发送时显示机构品牌，需要先开通白名单才能生效。仅在白名单（`manage_cy_company_logo`）内的机构，显示方形logo的设置项；非白名单机构不显示，避免对用户形成干扰。

> **注**：本需求材料未提供接口文档（无 Walle），按"材料不涉及接口时不臆造接口用例"规则，仅出功能用例。

## 测试设计方法选择

| 功能点 | 设计方法 | 说明 |
|---|---|---|
| 白名单机构显示设置项 | 等价类划分（有效等价类）+ 场景法（基本流） | 白名单内为有效等价类，主路径验证 |
| 非白名单机构不显示设置项 | 等价类划分（无效等价类）+ 场景法（备选流） | 非白名单为无效等价类，逆向验证 |
| 白名单变更后显示同步 | 边界值分析 + 状态迁移 | 刚加入/刚移出为边界点，白名单状态迁移 |
| 移出后重新加入数据保留 | 状态迁移（闭环）+ 错误推测 | 移出→重新加入的状态闭环，验证已配置数据一致性 |

## 测试点清单

### TP1: 白名单机构显示方形logo设置项（P1）

- 设计方法：等价类划分（有效等价类）+ 场景法（基本流）
- 覆盖：机构在 `manage_cy_company_logo` 白名单内 → 设置项显示
- 对应用例：功能用例

### TP2: 非白名单机构不显示方形logo设置项（P1）

- 设计方法：等价类划分（无效等价类）+ 场景法（备选流）
- 覆盖：机构不在白名单内 → 设置项不显示，其他设置项不受影响
- 对应用例：功能用例

### TP3: 白名单变更后设置项显示同步更新（P2）

- 设计方法：边界值分析 + 状态迁移
- 覆盖：
  - 机构加入白名单（状态迁移：非白名单 → 白名单）→ 设置项显示
  - 机构移出白名单（状态迁移：白名单 → 非白名单）→ 设置项隐藏
- 对应用例：2 条功能用例

### TP4: 机构移出后重新加入白名单已配置方形logo保留（P3）

- 设计方法：状态迁移（闭环）+ 错误推测
- 覆盖：机构在白名单内已配置方形logo → 移出 → 再次加入，已配置数据是否保留
- 对应用例：功能用例
- 备注：预期"数据保留"基于业务推断（移出不应删除已配置数据），建议与开发确认
